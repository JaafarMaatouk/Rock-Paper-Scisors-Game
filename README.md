# Rock-Paper-Scissors Game (C++)

A console-based Rock-Paper-Scissors game built in C++. The player competes against the computer for a user-defined number of rounds, with colorful terminal outputs for immediate feedback.

## 🎮 How to Play
1. When the game starts, enter the number of rounds you want to play (e.g., 3).
2. In each round, choose your move by entering a number:
   - `1` = Rock
   - `2` = Paper
   - `3` = Scissors
3. The computer will randomly select its move (1, 2, or 3).
4. The winner of the round is determined based on classic rules:
   - **Rock** crushes **Scissors**.
   - **Scissors** cuts **Paper**.
   - **Paper** covers **Rock**.
5. **Visual Feedback:** The console text color changes based on the round result:
   - **Green:** You win the round.
   - **Red:** You lose the round.
   - **Yellow:** It's a tie.
6. After all rounds are completed, the game displays the final winner along with a full summary of both players' scores.

## 🛠️ Requirements
- Visual Studio 2022 (or any modern C++ compiler).
- Windows OS (for the console color changing features).

## 🚀 How to Run
1. Clone this repository or download it as a ZIP file.
2. Open the `.sln` file in Visual Studio.
3. Press `F5` or `Ctrl + F5` to build and run the game.
